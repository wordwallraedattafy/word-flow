📚 الدروس

حفظ الكلمات الحالية كدرس

التخزين الدائم غير متاح في هذا العرض. الدروس تبقى حتى إغلاق الصفحة فقط، فصدّرها لحفظها.

☁️ مزامنة الدروس بين الأجهزة

اربط الصفحة بمشروع Supabase مجاني لتظهر دروسك نفسها على كل جهاز. رمز المكتبة بمثابة كلمة سر، فلا يقرأ دروسك إلا من يعرفه.

طريقة الإعداد (مرة واحدة)
  1. أنشئ مشروعاً مجانياً في supabase.com (زر New project).
  2. افتح SQL Editor والصق الكود أدناه ثم اضغط Run.
  3. من Project Settings ← API انسخ Project URL والمفتاح العام (anon أو publishable) والصقهما أعلاه.
  4. اضغط «إنشاء رمز» ثم «حفظ وربط». على الجهاز الآخر استخدم «رابط ربط جهاز آخر».
